# clean-c

Dense Clean Code principles tailored to modern C (C23), TigerStyle, and NASA Power of 10 systems programming.

## Install

```bash
npx skills add Octember/clean-c
```

## What It Covers

- **10-section C23 Clean Code reference**: Meaningful names with units, small single-purpose functions (`< 60` lines), bounded loops & guard clauses, file/module cohesion (`< 300` lines), single-source-of-truth data tables, arena ownership, `<stdckdint.h>` overflow-safe math, and boundary isolation.
- **Top 10 C Slop Smells**: Quick audit checklist for refactoring god headers, copy-pasted v1/v2 handlers, duplicated truth, and silent error drops.
